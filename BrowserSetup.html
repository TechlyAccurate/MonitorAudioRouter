Monitor Audio Router Browser Setup

Monitor Audio Router is installed. Browser support depends on the published browser extension IDs configured for this installer.

Normal Browser Windows

The installer registers the native messaging host for Chrome, Chromium, Edge, and Firefox. When published extension IDs are supplied, it also installs the browser extensions through the supported browser policy paths.

This build is configured for Chrome extension ID jnjminkakfohjeffdpeamngcnfneckog and Firefox extension ID monitor-audio-router@example.local. Browser policy installation can only fetch store extensions after the relevant store review makes them available.

Private and Incognito Windows

Private/incognito support is optional and off by default. Chrome and Edge require per-profile user approval for Incognito/InPrivate access. Firefox private browsing policy is enabled only when the installer is run with /enableprivatebrowsing.

Route Configuration

Use the tray menu's Open config command to assign audio devices to monitors. Leave a monitor set to Default to use the current Windows default playback device.

The browser extension sends audible browser window hints only to the local native messaging host. It does not send data to a remote server.
